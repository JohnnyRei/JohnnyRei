### Who's knocking

I build Power BI reports for a living. The charts are the easy part. The real work is the data model, the messy sources and the DAX that has to be right before anyone sees a dashboard.

When I'm not doing that, I write Python. Sometimes it's useful. Sometimes it's a programming language that talks like folks from Minas Gerais.

### Uai, sô

That language is [Mineiro](https://github.com/JohnnyRei/Mineiro-Language), and this is me introducing myself in it:

```text
# johnny.trem

VAR nome = "Johnny"
VAR cidade = "Uberlândia"
VAR xicaras = 3

FUN apresenta()
  UAI("Uai, sô! Eu sou o " + nome + ", de " + cidade + ".")
  UAI("Trabalho com dados e faço relatório no Power BI.")
END

apresenta()

FOR i = 0 TO xicaras THEN
  UAI("Mais um cappuccino, pra garantir.")
END
```

`UAI` prints, `FRAGAR` reads input, `TREM` is true and `PAIA` is false. Files end in `.trem`, like the train.
